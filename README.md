# 🏙️ Airbnb Analysis – Mexico City (CDMX)  
Data Analysis & Pricing Insights  

## 📊 Overview  
This project analyzes Airbnb listings in Mexico City to uncover patterns in pricing, location, and demand.  

The goal is to understand what factors influence nightly prices and how location and listing characteristics impact performance.  

## 🎯 Objective  
Answer key business questions such as:  
- What factors influence Airbnb pricing the most?  
- Which areas are the most expensive or profitable?  
- How do reviews and demand relate to pricing?  

## 📁 Project Structure  
- `/data/listings.csv` → Raw dataset (Inside Airbnb)  
- `/notebook/airbnb_cdmx_analysis.ipynb` → Full analysis  

## 🛠️ Technologies  
- 🐍 Python 3  
- 📓 Jupyter Notebook  
- 📊 Pandas, Matplotlib, Seaborn  
- 🤖 Scikit-learn  

## ⚙️ Process  
- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- Visualization of trends and patterns  
- Feature exploration for pricing insights  

## 📈 Key Findings  
- 📍 Premium areas like Condesa and Polanco have the highest prices  
- ⭐ Number of reviews does not always correlate with higher prices  
- 🏠 Location plays a stronger role than listing popularity  
- 📊 Price distribution varies significantly across neighborhoods  

## 🚀 How to Use  
1. Clone this repository  
2. Open the notebook in Jupyter  
3. Install required libraries (`requirements.txt`)  
4. Run all cells  

## 💼 Business Value  
This analysis helps:  
- Understand pricing behavior in competitive markets  
- Identify high-value locations  
- Support better pricing strategies  
- Provide insights for investment decisions
